# HunteraFarm

Site oficial de download do HunteraFarm, um player para Windows que mantém duas sessões do Huntera separadas em uma única janela.

Site público: <https://cacor11.github.io/HunteraFarm/>

## Site

O conteúdo público fica na pasta `site` e é publicado automaticamente pelo GitHub Pages.

## Instalador

O instalador não fica dentro do repositório. Ele é distribuído pela área **Releases**, na versão `v1.0.0`, com o nome:

`HunteraFarm-Setup-1.0.0-x64.exe`

## Aviso

HunteraFarm é um projeto independente e não oficial, sem vínculo com o Huntera ou seus responsáveis.
